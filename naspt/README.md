# naspt — 基德盘搜 1:1 复刻

原站：https://naspt.vip/（基德盘搜 - 网盘资源搜索引擎）

本项目按原站页面结构与视觉 1:1 复刻，纯静态多页站：

| 路径 | 页面 |
| --- | --- |
| `index.html` | 搜索首页（Hero 搜索、公告、每日更新、热门搜索、热播榜） |
| `discover/` | 热播榜（电影/剧集/动漫/综艺/短剧分频道） |
| `today/` | 每日更新（分页） |
| `hot/` | 热搜榜（含搜索次数） |
| `app/` | APP（PWA 添加主屏幕说明） |
| `search/?q=` | 搜索结果（在快照内检索） |
| `resource/?id=` | 资源详情（快照内信息 + 去原站获取） |
| `friend-links/apply/` | 申请友情链接 |

## 数据

- `data/` 为原站公开接口（`https://naspt.vip/api/public/*`）的快照：站点配置、每日更新（前 5 页 120 条）、热搜榜、热播榜 5 频道各 20 条。
- 刷新：`python3 scripts/refresh.py`（零依赖；失败保留旧数据）。
- 海报与联系二维码为原站公开图片地址直引，未入库二进制文件。
- 原站接口未开放跨域，线上页面无法实时调原站搜索；搜索页在快照内检索，全站结果链接回原站。

## 说明

复刻范围为页面结构、布局与视觉样式；资源链接的实际获取（网盘地址投递）在原站完成。
