## 二、通用派发规程

- 分批：一批 = 一台机 + 一件事 + 一份说清的交付物。拆批按能力对口：算力批（打包、跑批、拉数据）给 Kaggle，其次 Colab；整机批（要桌面、要常驻环境）给 InstaBox；只进不出的试验给 Simular。互不依赖的批可并行，共享同一会话 / 同一窗口的批必须串行。
- 额度感知：派批前先看额度与状态——Kaggle GPU 30 小时 / 周、TPU 20 小时 / 周（CPU 会话宽松但同样受会话时长管）；Colab 免费层动态限流，用得狠先被限的是它；InstaBox 无额度概念但会睡，长批要预估唤醒成本。
- 投递三通道：短命令直达通道执行；成段逻辑打包成脚本文件投递后在机上跑；数据与源码走各机正道进（Kaggle 数据集、Colab 挂 Drive、InstaBox / Simular 文件直传或直拉 URL）。
- 开工先验：每批开工先确认通道活着——会话 / 运行时还在、要用的缓存与环境还在；验不到就如实标注是冷跑，不许拿暖跑口径冒充。
- 回收：产物一律先回到总控所在的 VM 验过（能验哈希的验哈希、能验签的验签），再汇总成一份结果报负责人；单台的原始输出不直接当结论。
- 失败处理：先分类再动作——额度尽、休眠、网络不通、环境缺失、通道断，各有各的解法；禁止原样无脑重试，同一批连续失败先停批、把原因报上来再说。
- 会话铁律：任何账号的唯一已登录窗口不许关，关窗前先开新窗口验证会话能继承；长暂停的批要给会话保活，别让它闲置到自动关闭。

## 三、各机通道现状

## 四、AI 比价数据获取

### 数据源

- 聚合站接口：aiprice.club 与 cardnav.xyz 的 /api/shop-products.json，一次给全量商品（压缩格式，商品表与店铺表分开，靠下标关联）。注意：aiprice.club 的分类全量页必须带完整浏览器请求头才给全量，短请求头只返回瘦页，会误判数据量。
- PriceAI：商品页服务端渲染可直读，但只渲染按价升序的前 12 条，分页参数无效，只够看头部价。
- 16688：官方接口直拉，店铺与商品是两个层级（一店多商品），库存与限购以详情接口为准。
- 自营店：链动小铺、卡信等店铺页与各自接口，能直拉的直拉。
- 浏览器池：脚本过不去的源（如 wzyp）走云浏览器慢爬補齐。
- HuabF 接码：公开接口免登录直拉——sms.huabfoo.store/api.php?action=services 给全量服务目录，action=offers&product=<服务名> 给各国实时价与库存。

### 管线

- GitHub Actions 每小时跑 frontend/ai-shop/scripts/refresh.py：抓各源 → 合并去重 → 生成看板 board.json（网站版 10 组、每组上限 30 条）→ 维护全量池（见下）。
- 护栏：新一轮总量低于上一轮一半时中止覆盖，宁可不更新也不许薄数据冲掉好数据。
- 一手价优先：详情页一手价覆盖聚合价，覆盖 72 小时内有效；看板价不可核验视为错。

### 数据布局（frontend/ai-shop/data/）

- board.json：看板成品（10 组 + 价格段），网站直接读它。
- shops.json：店铺目录。
- maps.json：平台短码映射（新平台并入池前，先在这里注册短码）。
- price-log/：全量池，按来源分片——16688、wzyp、catfk、aicdks、huabf、web（未映射的自营店，键用完整网址）六片，外加 index.json 清单（总量、各片条数与字节数）。价格点不许再写回单一大文件。

### 格式铁律（现行 v3）

- 键：平台短码:商品 ID（如 16688:G51176638、huabf:openai/US）。
- 值：三元组差分序列 [分钟戳, 价, 来源码, 间隔分钟, 价, 来源码, …]；来源码 1 = 脚本抓、2 = 浏览器抓、3 = 人工补充。
- 改池只做外科替换：推共享文件前紧贴动作重拉最新底版，只换自己负责的段 / 片，并断言其余部分零差异；严禁用旧格式或本地过期副本整份覆盖（2026-11-12 曾因此把全量池冲掉一截，靠底版备份才恢复）。
- 推送通道有体量上限：小文件走常规推送；单文件超过约 5 MB 走 GitHub 网页上传（上限 25 MB）。

### 分批查法

- 先读 price-log/index.json 看清单，再按需要只拉对应的片：查接码只拉 huabf 片，查链动只拉 wzyp 片，不整份拖全量池。
- 派送到别的机器同理：按片取文件，变过的片才需要重送。

### HuabF 特别说明

- 现行 huabf 片是 2026-11-12 的一次性全量快照（110,148 条），不随每小时管线自动更新；要新价，重跑拉取后按 v3 格式只重并 huabf 片。
- 该站页面成功率标注为 0%、收码未实测，属未证真来源；负责人真要用时先小额试，验过再充钱。
