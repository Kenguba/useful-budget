# 动效自然度

- **动效自然度（2026-11-07 定，全站适用）**：（1）随时打断——可被操作打断的动效用 `transition` 实现，不用 `@keyframes`；动效进行中再次操作须从当前状态就地转向新目标，不得从头重播或等播完才响应。（2）轻轻退场——退场元素只移出一小段（约 20–50px）即同步淡出并加轻微模糊（位移、`opacity`、`blur` 一起收尾），不得一路飞出屏幕。（3）柔和切换——内容 / 图标切换用交叉淡化，叠加轻微缩放与模糊，不得瞬时显隐硬切。（4）入场缓出——入场动画用强缓出曲线 `cubic-bezier(.16, 1, .3, 1)`，不用匀速 / 线性；验收须用回放加慢动作逐帧自查并与速度 / 位置曲线对比，只凭正常速度肉眼看一遍不算验收。（5）无意义循环禁——呼吸发光、pulse / ping、视差漂浮不用，非实时状态一律静态。（6）不用 `transition-all`，须点名过渡属性；悬停只变颜色或表面、不放大，按压才微缩。（7）只动画 `transform` 与 `opacity`，不动画宽高、`top` / `left` 与大面积模糊（弱设备卡顿源）。（8）分组高亮滑动——分组导航的移动高亮，组内切换滑动跟随；跨组切换不滑动、不扫过无关项，旧高亮淡出、新高亮淡入；用 View Transitions 时每组用不同的 view-transition-name 区分。
