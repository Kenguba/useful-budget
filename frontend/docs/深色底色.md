# 深色底色两档结合

- **深色底色两档结合（2026-11-16 定，全站适用）**：深色底色按语义分四级、每级 B 通道比 R/G 高 2（微冷碳灰），全站只用这四级、不另调近似灰；日常页面用小步档——页面底 #000000（纯黑 OLED）、卡片 #0A0A0C、卡内层 #121214、最高层 #1C1C1E，分层靠发丝边框、不靠阴影；浮层（弹窗、菜单、下拉）用大步档——整体抬一级，底 #1C1C1E、卡片 #2C2C2E、内层 #3A3A3C，与日常页拉开距离；碳灰变体只把日常档整体上移半级（页面底 #09090B、卡片 #121214、内层 #1C1C1E），层级关系不变；文字不用灰色值，用 #EBEBF5 按 100% / 60% / 30% 透明度分主、次、弱三级；深色不用渐变、发光与阴影分层
