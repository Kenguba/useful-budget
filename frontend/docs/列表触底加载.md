# 列表触底加载

- **列表触底加载（2026-11-03 定，全站适用）**：凡是分页 / 分批展示的列表，一律做成滚动触底自动加载下一批，不做「加载更多」按钮、不做「上一页 / 下一页」分页。实现借鉴 `frontend/pages/ai-shop/` 店铺目录的哨兵模式：`IntersectionObserver` 哨兵元素 + `rootMargin` 提前约 300px 触发 + 在途锁防重复触发 + 加载中转圈提示；全部加载完显示「已展示全部 N 条」；拉取失败不得空转自动重试，给一次点击重试即可。参考实现：`frontend/pages/ai-shop/index.html`（店铺目录哨兵）、`frontend/pages/pan-cloud/assets/app.js`（每日更新页）。
