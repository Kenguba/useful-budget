02

两条首选路线，说细一点

以下标注区分来源性质：为微信/腾讯官方文档原文，为开源项目官方文档，为论坛与实测反馈，仅作经验参考

路线 A · 官方 ClawBot（iLink 协议）

零封号 · 体验最佳

你在微信里聊天的对象是一个新增的 ClawBot 机器人会话，不是「你的号被程序接管」——这是它和所有逆向框架的本质区别

接入方式腾讯官方仓库 Tencent/openclaw-weixin，扫码登录；要求 OpenClaw ≥ 2026.3.22、Node ≥ 22.13
收消息POST /ilink/bot/getupdates 长轮询，服务端 hold 约 35 秒，游标推进，无需公网回调
发消息POST /ilink/bot/sendmessage，域名 ilinkai.weixin.qq.com，纯 HTTP/JSON
支持范围仅私聊；文本、图片、语音、文件、视频均可收发，语音由微信云端转文字
  • 实时性：长轮询近实时，AI 生成多久就多久，没有公众号那种 5 秒被动回复限制，你要的「1 分钟内回复」天然成立
  • 主动推送的真实边界：发送必须回带入站消息的 context_token，第一句话必须由用户先发；PushPlus 的渠道说明称每下发 10 次后需再主动发起一次对话、每隔 24 小时也需要一次；也有社区实现称文本用空 token 可长期推送、被拒后需用户发消息激活——口径互相有出入，按「不可靠」规划，重要提醒不要压在这一条上
  • 运维注意：网关停机数小时后 token 失效（errcode -14 会话过期），需重新扫码；CowAgent 的客户端会自动清凭证重新拉起扫码流程
  • 上手最快的方式：CowAgent、AstrBot、LangBot 均已接入此通道；若只做桥不想引入全家桶，可直接照官方协议文档用 HTTP/JSON 对接自己的 Webhook

路线 B · 企业微信自建应用 + 微信插件

真主动推送 · 官方 API

唯一同时满足「1 分钟内异步回复 + 无窗口真主动推送 + 个人可注册」的老牌官方路线，代价是形态像企业应用、且出站调用必须走固定 IP

注册门槛帮助中心有「个人组建团队」入口，一个微信号可建 5 个企业；企业验证费 300 元起，不验证也能建自建应用
未认证限制通讯录成员上限 100、通讯录上限 1000、内部群上限 500、外部联系人全企业共享 100——1 人自用基本无感
收消息回调验证须 1 秒内返回明文 echostr；消息以加密 XML 推送，5 秒不响应重试 3 次，可先回空串再异步补发
发消息message/send 支持文本/图片/文件/markdown/模板卡片等，无 48 小时窗口；频控同应用同成员 30 次/分、1000 次/时
  • 在个人微信里用：管理后台「我的企业 → 微信插件」生成邀请二维码（有效期 7 天），个人微信扫码关注后，在微信「通讯录 → 我的企业」里就能收应用消息并回复；2025–2026 该功能仍然存在，企微开发者中心 FAQ 至今在维护其排障条目
  • 配置避坑：不要勾「仅在企业微信中接收消息」；不要给应用设「在微工作台中始终进入主页」，否则微信端只能收到文本且截断为 20 字节，其余类型变成「去企业微信查看」提示
  • 硬性前提：新自建应用必须把调用方 IP 配进「企业可信 IP」，否则报 60020；未认证企业可用 http://公网IP:端口 做回调，认证企业则要求与主体一致的备案域名
  • 别填虚假企业资料注册未认证企业，多方实测消息接口无需认证即可使用，以管理后台当日显示为准

能用但不推荐当主力的三条

微信客服 kf

窗口内异步可以 · 冷启动不行

用户侧体验是微信内最像原生聊天的客服会话，不用加好友、不用关注公众号，点客服链接或扫码即进会话，可发文本/图片/语音/视频/文件

  • 门槛：必须先注册企业微信再开通微信客服；未完成企业验证且未绑定视频号时，可咨询的微信用户数量有上限（具体数字官方未公开，条款称以页面展示为准），验证并绑定视频号后不限量
  • 收消息有个坑：回调只推 kf_msg_or_event 事件通知，消息正文不在回调里，必须再调 sync_msg 用游标增量拉取（仅近 3 天消息，游标要入库保存）
  • 发消息被锁死：仅当客户处于「新接入待处理」或「由智能助手接待」状态可发；客户发消息后 48 小时内最多 5 条，条款 2.4 明说 48 小时后无法主动发送——定时提醒不成立
  • 口径冲突，须实测：CowAgent 的微信客服通道把「已认证企业微信」列为前提，与条款「未验证可开通但限人数」不一致；只有自己一个人咨询的话限量版大概率够用，但能否以未认证主体开启 API 收发，建议注册后在后台当日实测

来源：微信客服功能服务条款 · kf 接收消息 · kf 发送消息 · CowAgent 微信客服通道

公众号（个人订阅号 / 个人服务号）

死穴：没有异步下发通道

能开服务器配置、能被动回复，卡点只有一个但致命：个人未认证号用不了客服消息接口，AI 慢慢想出来的答案没有任何 API 能推给用户

  • 被动回复 5 秒：微信服务器 5 秒内收不到响应就断开并重试，共 3 次；处理不完时官方要求直接回 success 或空串，后续靠客服消息异步回复——而这一步个人号做不到
  • 客服消息的适用范围写死了：公众号、服务号均为「仅认证」，定义为「仅允许企业主体已认证账号调用」；个人主体无法完成企业主体认证，个人订阅号、个人服务号都拿不到
  • 框架的实际玩法：CowAgent 等对个人订阅号采用「先回一句『正在思考中』，生成完攒着，等用户再发任意一条消息，再把答案作为被动回复带出」——慢回复不会自动到达，必须用户再戳一下，不满足「1 分钟内自动回复」
  • 文档里的「15 秒」别信：那是把 3 次重试累计成的经验窗口，不是官方单次时限承诺，依赖它攒 AI 回复并不可靠
  • 个人服务号（2024-10 开放）救不了：个人不能做微信认证，高级接口仍无权限，接口能力与个人订阅号基本相同

逆向个人号框架

集体退场或高风险

AstrBot 在 Issue 里把社区共识说得很直白：不再主动集成新的微信个人账号接入方案，因为官方对第三方自动化接入个人账号有严格限制，相关方案经常失效或不稳定——这也是三家开源项目齐齐转向官方 ClawBot 的原因

WeChatFerry — 已退场

DLL 注入 Hook 旧版 PC 微信 3.9.12.x；仓库已归档只读，作者 2025-06 宣布停维，旧版客户端登录正被「版本过低」拦截；2025-04 社区集中反馈 1 天被警告、强制下线

Gewechat — 已停维

仓库自称「技术归档」、不含完整服务端实现，2025-05 起停止维护、无法登录；AstrBot 已改接 WeChatPadPro 替代

itchat / Web 协议 — 基本已死

微信 4.0 起渲染架构从 Qt Widgets 迁到 Qt Quick，控件树变黑盒，原版 2025-10-28 停维；现行付费版 wxautox4 适配 4.1.x，要常驻 Windows 且窗口保持在桌面

中转层：Cloudflare 怎么摆

结论：入站回调放 Worker 完全可行且有成熟做法；出站调微信 API 这一步不能放 Worker，必须落回固定 IP 的云服务器——这是整条链路最容易忽略的一坑

  • 域名坑：回调地址优先绑自己的域名到 Worker，不要用 *.workers.dev——Cloudflare 官方文档明说该域名强制 Browser Integrity Check 且无法关闭，部分客户端会在 Worker 运行前被 1010 拦截，且其在大陆的连通性历来不稳定，微信服务器能否稳定回调未获任何官方保证
  • 白名单坑：公众号只有白名单 IP 能调取 access_token（错误 61004/40164），企微只有「企业可信 IP」能调任何接口（60020）；而 Worker 出站 IP 不固定、会变化，所以取 token 和一切回推调用都由固定 IP 服务器执行，Worker 只做验签、解密、入队
  • 去重必做：微信 3 次重试会重复投递，入队前按 MsgId（事件用 FromUserName + CreateTime）排重，这是官方明确推荐的做法
  • 图片也要走服务器出站：公众号/企微/kf 回图片不是发图片 URL，要先调素材上传接口换 MediaId；ClawBot 则有自己的 CDN 上传接口，由网关完成

来源：Cloudflare workers.dev 说明 · 公众号 API 与 IP 白名单 · Cloudflare 构建公众号后端教程（2025，社区实现）

落地顺序建议

  1. 先上 ClawBot 聊天（半天内可跑通）用 CowAgent 的微信通道或直接照腾讯官方 iLink 协议对接，扫码即通，先把「在微信里聊天、发图、1 分钟内回复」这条主体验落地
  2. 再补企微提醒通道注册未认证企业微信（个人组建团队）→ 建自建应用 → 配回调与企业可信 IP → 个人微信扫码关注微信插件；定时提醒、冷启动通知全走 message/send
  3. 中转层按分工摆回调入站可放 Cloudflare Worker（绑自有域名、验签入队、立即回 success），出站调用一律回固定 IP 服务器执行，不要把 access_token 和回推放在 Worker 上
  4. 正式投入前做一次端到端实测本次为案头调研，未实测任何路线；企微未认证链路有多方社区教程背书，但微信后台策略调整频繁，建议按 CowAgent 企微文档实际跑一遍再定型
  5. 主力微信号不碰逆向框架WeChatFerry、Gewechat、itchat 已退场，PadLocal / Gewe 付费版是花钱买封号与隐私风险，与上面两条官方通道没有可比性
