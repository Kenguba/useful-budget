小白建站工具全图与三套搭配

建站四层架构

先把市场上最常见的建站工具一次看全：一类是 AI 应用里能连接的服务，一类是免费建站清单里的托管平台；两边有重复，合起来 16 个工具，它们不是互相替代的竞品，而是一个网站的不同零件；先记住一句话：页面放哪、数据存哪、AI 用谁、重复劳动交给谁，四个问题各选一个工具，就是一套完整搭配；只做展示页时只需要第一个，其余三层按需要再加，不要一上来全装上

第一层 必备起步

页面托管

把页面放到网上，给出能打开的网址

GitHub Pages Cloudflare Pages Vercel Netlify Surge PinMe Zeabur Railway Render
第二层 按需加装

数据与后端

存数据、做用户登录、跑常驻的服务器程序

Supabase Cloudflare (Workers 与 R2) Zeabur / Railway / Render 亦可兼任
第三层 按需加装

AI 大脑

对话、写作、看图、写代码的能力，通过接口接进自己的网站

Anthropic（Claude） Google Gemini
第四层 按需加装

自动化与抓取

把重复流程串起来自动跑，或把公开网页数据抓下来

Make n8n Apify
特别提示：Cloudflare 单独说一句：它既是第一张图里的平台本体（管域名解析、加速和防护，还能跑 Workers 小程序、存文件），也是 Cloudflare Pages 的出品方；Pages 是它的页面托管产品，两者是同一家公司的不同产品，不要当成两个重复选项

16 个工具一览

同一层里选一个就够，区别主要在顺手程度和免费额度的给法，具体额度以各官网为准

总结：托管这一层看着有九个，其实只分三种：纯静态的（GitHub Pages、Surge、PinMe）只能放做好的页面；前端加轻函数的（Cloudflare Pages、Vercel、Netlify）还能顺手处理一点简单逻辑；全栈的（Zeabur、Railway、Render）前后端和数据库都能跑；网站越简单，越往前选

免费额度预警（先纠正几个标题党）
Railway 不是真免费，新号先给 30 天 5 美元试用，之后免费档每月只剩 1 美元额度，常驻服务基本要上 5 美元/月的 Hobby；Zeabur 免费档主要是让你管理 1 台自己的服务器，算力另外算钱；Vercel 免费档只许个人非商用；PinMe 把页面用到 IPFS 上，免费档整站 1GB，但绑自己的域名要付费档

搭配 A

个人主页、博客、文档站（只展示内容）

GitHub + Cloudflare Pages + Cloudflare（绑域名）

适合只有展示内容的网站：主页、博客、作品集、项目文档；不需要登录、不需要存数据，是最简单、最稳妥的一套入门搭配

动手步骤（可点击勾选记录进度）
备选：更省事的备选：只用 GitHub Pages 一家，仓库设置里打开 Pages 就有网址，适合先练手；这一套可以零元跑起来，需要花钱的只有域名本身
搭配 B

带登录和数据库的完整小网站（要登录和存数据）

Vercel + Supabase + Cloudflare（绑域名）

适合要用户注册登录、要存数据的网站：留言板、记账、收藏夹、小型管理工具；分工是 Vercel 放页面，Supabase 管登录和数据库，页面存取数据直接调用 Supabase，不用自己写后端、不用自己装数据库；诀窍是能不用常驻后端就不用，也就躲开了免费档休眠、试用过期的坑

动手步骤（可点击勾选记录进度）
备选：怕两家平台来回切换的，用全包备选：Zeabur 或 Railway 一家把前端、后端、数据库全放下，中文界面、上手最低优先选 Zeabur；代价是灵活性和可迁移性不如分开搭配，但对第一个全栈练手项目完全够用
搭配 C

AI 小工具与自动采集站（要 AI 功能或自动抓数据）

Vercel 或 Cloudflare Pages + Anthropic 或 Gemini + Apify + Make 或 n8n + Supabase

适合带 AI 功能或要自动抓数据的网站：AI 问答小工具、自动汇总资讯、定时抓价格再展示；页面平台负责展示，AI 负责理解和生成，Apify 负责抓公开数据，Make 或 n8n 负责定时把流程串起来跑，Supabase 负责把结果存下来给页面读

动手步骤（可点击勾选记录进度）
备选：两个二选一：AI 大脑在 Claude 和 Gemini 之间选一个起步就够；自动化在 Make 和 n8n 之间，不想自己部署、想拖拽上手选 Make，想免费自部署、数据自己掌控选 n8n；进阶插件等站跑起来再加，不用一开始就配
安全硬规矩 AI 的接口密钥只能放在服务器一侧（平台的函数或环境变量里），绝不能写进网页前端，写进去等于公开送人
费用与合规口径 三套搭配起步都可以零元，免费额度对学习和个人小流量通常够用；开始付费的触发点也很一致：流量或用量超出免费额度、要长期常驻不休眠的后端、AI 按调用量计费、抓取按运行量计费、以及自己买域名；各家具体价格和额度经常调整，本文不写死数字，动手前到官网定价页看一眼现行口径为准；抓数据时只抓公开内容，并遵守目标网站的规则和条款

16 个工具官网链接清单

额度按 2026-11 的官方口径写，官方会不时调整，动手前点直达链接看一眼现行数字；唯一硬提醒：域名开了橙云代理后，国内访问会绕到海外节点，延迟比国内云高，图省钱就要接受这一点

Agent 与云电脑背后的巨模型

Muse、Cue、Dots、Grok Bot、Gemini Spark、Devin、Hark、Cowork：背后的大模型与配的云电脑

这一节只看最典型的八个，外加 Cue 的底座 Manus 本体；每个只回答两个问题：背后的巨模型到底是谁的，是自研的还是借别家的；后面配的那台云电脑是什么

01 · 大脑

大模型 = 大脑

负责想和判断，聪不聪明主要看它

02 · 调度

Agent 框架 = 调度

负责拆任务、选工具，把活一步步派下去

03 · 工位

云电脑 = 工位

负责真的去开浏览器点网页、装软件、跑代码、存文件；只有大脑、没有云电脑的只能在聊天框里回答你，配上云电脑的，你把手机关掉，它能在云上接着把活干完

这一批的共同点：这八个都配了云电脑，只是配法不一样：有的常驻，有的按任务临时开
归组口径硬性规定：只看两件事——直接归属的公司是不是中国公司、运营地在哪；「有中国团队、中国人创办」只是出身，只注明、不决定归组；出身、归属、运营地是三件不同的事，不许混；格式统一写成「名称（所属）」，括号里是所属

国外组（共 9 条）

含 Manus 本体
归组特别说明：Cue 和 Manus 为什么归国外组，一句话说清：直接是中国公司就要受中国监管这一套，麻烦很多，Manus 当年把总部迁到新加坡、把运营主体换成新加坡的 Butterfly Effect Pte（开曼架构控股），正是为避开这个，所以按归属和运营地它算国外，出身是中国团队创办只在这里注明；后来腾讯牵头的中方资本回购后成了它最大单一股东，但那是少数股权、不控股，公司还是独立运营、总部仍在新加坡，所以归属不变
国内组：按定死的口径，这一批为空：没有一个是「直接归属中国公司、又在中国运营」的，最接近的 Cue 和 Manus 也只是中国团队创办出身，归属和运营都已经在新加坡，所以归国外组；这一组不硬凑数，不拿出身当归组，也不拿不相干的产品来填

云电脑对比与总结

从大模型这一项看，几家的含金量也清楚了：Muse、Hark、Dots、Gemini Spark 和 Cowork 是自己养模型，脑子是自己的；Devin 一半自己养、一半可换别家的；Grok Bot 不公开用谁、按任务自动路由，自家的和别家的都可能被调到；Cue 和 Manus 没有自己的脑子，聪明程度取决于它调用的 Claude 和通义千问，自己的本事在调度和那台云电脑上

产品（所属） 云电脑的名字 常驻还是按任务开 你离线后

Cue (Manus)Manus 常驻云电脑常驻，全天在线的 Ubuntu 虚拟机下线以后继续干

评估新 Agent 的口诀：以后再看到一个新的 Agent 产品，就问三句，立刻能看懂它：第一句，背后的巨模型是谁的，自研还是借的；第二句，后面配没配云电脑，叫什么；第三句，那台云电脑是常驻的还是干完一个任务就没了的；第四节管第一句，这一节管后两句

自办虚拟卡选型

前面几节选的 AI 订阅大多要绑一张能付美元的卡，这一节讲怎么自己办一张自己名下的 Visa 虚拟卡：自己在发卡平台注册、实名、充值，付正价订阅，不用小贩卖的成品卡、长租卡

路线

自己在发卡平台注册、实名、充值，开自己名下的 Visa 虚拟卡，付正价订阅；不用小贩成品卡、长租卡

充值

用 USDT 充，按月充、按月花，不在卡里存大额

用途

付 AI 订阅月费；过 Muse 年龄验证（卡预授权 1 美元，5-7 个工作日退）

先分清

小贩卖的 0 刀耗材卡是另一回事，0 刀卡过不了 Muse 验证

五家虚拟卡平台对比

Gate 卡

平台最稳
定位：
虚拟卡免费开，刷卡从账户现扣；多个教程证实能过 Muse 绑卡
费用：
兑换约 0.9%、非美元外汇约 1%（第三方口径，以 App 内为准）
门槛：
KYC 最严：2 级认证（证件+人脸），部分卡还要近 3 个月地址证明；官方受限地区含中国大陆，大陆居民新申资格被排除，已有账号且 App 内能申到的另说
注意：坑在用法：拿假地址绕资格开卡会被冻号冻钱

PokePay

首选
定位：
香港 Visa 虚拟卡，官网 pokepay.cc
门槛：
KYC 一级（身份证/护照+人脸）
费用：
0 月费 0 年费；开卡费原价 20 美元、邀请券后约 5–7.2 美元；充值费 1%、消费 1%、非港币转换 1%；USDT（TRC20）充值；首充建议 45 USDT

Roogoo（乐享卡）

仅快进快出
定位：
美国 Visa，官方明列支持 AI 订阅；其香港卡种不支持 AI 订阅，须选乐享或尊享
门槛：
要 KYC（证件+人脸）

首卡 0 开卡费、首充 10 美元、充值 0%、交易费 1%

一次性用途

国内外 AI 名单：热度榜与智能度榜

国外和国内主要的 AI 全收进来：一共 24 家，国外 10 家、国内 14 家，口径是市面上主流、初学者最常接触到的巨模型厂商，一个不落；这一节不混排，做成两张榜：热度决定生态与顺手程度，智能度决定上限，两件事差别很大（比如 Meta AI 热度靠前但智能不在第一梯队，Claude 正好反过来）；每家都带代表产品或模型、一句话特长与建站用途；第一节搭配里 AI 站在第三层「AI 大脑」的位置，选大脑时对照这两张榜挑

热度以用户量和访问份额为准；前十名有公开量级数，其后各家按大致量级靠后排

榜单使用指南与总结

一句话总结：最聪明的是 Claude、Gemini、GPT 三家，最热的是 ChatGPT、Meta AI、Gemini、豆包；国内智能看通义和 DeepSeek，热度看豆包、通义、DeepSeek

选型策略：做纯展示站（搭配 A）用不上 AI；要登录与数据（搭配 B）一般也先不用；只有做 AI 小工具或自动采集站（搭配 C）时才选大脑：要上限看智能度榜前列，要省钱与中文顺手看 DeepSeek、通义千问、豆包、Kimi、GLM；写代码第一梯队是 Claude、GPT、Gemini、DeepSeek、通义千问，这 5 个轮着用基本够了；一个够用，互为备用再加第二个

国内厂商优势与开源：国内这 14 家共同的好处是不用绕海外网络、中文原生、API 便宜，站要面向国内用户、调用量又大时优先用它们；能开源自部署的是 Llama、通义千问、DeepSeek、GLM、Mistral，能搬回自己的服务器上自己跑，其余都是只能调用人家云上 API；接口密钥的规矩不变：只能放服务器一侧，绝不能写进网页前端
