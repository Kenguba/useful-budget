01

小白建站工具全图与三套搭配

先把市面上最常见的建站工具一次看全：一类是 AI 应用里能连接的服务，一类是免费建站清单里的托管平台；两边有重复，合起来 16 个工具，它们不是互相替代的竞品，而是一个网站的不同零件

先记住一句话：页面放哪、数据存哪、AI 用谁、重复劳动交给谁，四个问题各选一个工具，就是一套完整搭配；只做展示页时只需要第一个，其余三层按需要再加，不要一上来全装上

先分清四层

第一层01

页面托管

把页面放到网上，给出能打开的网址

这一层的工具GitHub Pages、Cloudflare Pages、Vercel、Netlify、Surge、PinMe、Zeabur、Railway、Render
第二层02

数据与后端

存数据、做用户登录、跑常驻的服务器程序

这一层的工具Supabase、Cloudflare（Workers 与 R2）；Zeabur、Railway、Render 也能兼这一层
第三层03

AI 大脑

对话、写作、看图、写代码的能力，通过接口接进自己的网站

这一层的工具Anthropic（Claude）、Google Gemini
第四层04

自动化与抓取

把重复流程串起来自动跑，或把公开网页数据抓下来

这一层的工具Make、n8n、Apify

Cloudflare 单独说一句：它既是第一张图里的平台本体（管域名解析、加速和防护，还能跑 Workers 小程序、存文件），也是 Cloudflare Pages 的出品方；Pages 是它家的页面托管产品，两者是同一家公司的不同产品，不要当成两个重复选项

16 个工具一览同一层里选一个就够，区别主要在顺手程度和免费额度的给法，具体额度以各官网为准

托管这一层看着有九个，其实只分三种：纯静态的（GitHub Pages、Surge、PinMe）只能放做好的页面；前端加轻函数的（Cloudflare Pages、Vercel、Netlify）还能顺手处理一点简单逻辑；全栈的（Zeabur、Railway、Render）前后端和数据库都能跑；网站越简单，越往前选

免费口径先纠两个标题党：Railway 不是真免费，新号先给 30 天 5 美元试用，之后免费档每月只剩 1 美元额度，常驻服务基本要上 5 美元/月的 Hobby；Zeabur 免费档主要是让你管理 1 台自己的服务器，算力另外算钱；Vercel 免费档只许个人非商用；PinMe 把页面发到 IPFS 上，免费档整站 1GB，但绑自己的域名要付费档

三套小白搭配按需求从少到多排列，照着自己那一套做，不要跨套混搭

A

个人主页、博客、文档站

只展示内容
GitHub ＋ Cloudflare Pages ＋ Cloudflare（绑域名）

适合只有展示内容的网站：主页、博客、作品集、项目文档；不需要登录、不需要存数据，是最简单、最稳妥的一套入门搭配

  1. 用同一个邮箱注册 GitHub 和 Cloudflare 两个账号
  2. 在 GitHub 建仓库，把页面文件放进去（不会写就让 AI 生成，或套一个现成模板）
  3. 在 Cloudflare Pages 里点「连 GitHub 仓库」选这个仓，它自动部署出一个 pages.dev 网址，网站当场就能打开
  4. 有自己的域名就绑上，DNS 也在 Cloudflare 里改，一处搞定
  5. 以后改站只管往仓库里更新，网站自动跟着更新，不用再手动传文件

更省事的备选：只用 GitHub Pages 一家，仓库设置里打开 Pages 就有网址，适合先练手；这一套可以零元跑起来，需要花钱的只有域名本身

B

带登录和数据库的完整小网站

要登录和存数据
Vercel ＋ Supabase ＋ Cloudflare（绑域名）

适合要用户注册登录、要存数据的网站：留言板、记账、收藏夹、小型管理工具；分工是 Vercel 放页面，Supabase 管登录和数据库，页面存取数据直接调用 Supabase，不用自己写后端、不用自己装数据库；诀窍是能不用常驻后端就不用，也就躲开了免费档休眠、试用过期的坑

  1. 在 Supabase 建项目，先建好数据表并打开登录功能，拿到项目地址和访问密钥
  2. 页面代码放 GitHub，在 Vercel 连接仓库并填入 Supabase 的地址和密钥
  3. 上线后在 Cloudflare 绑自己的域名
  4. 先自己注册一个账号走通登录和存数据，再给别人用

怕两家平台来回切换的，用全包备选：Zeabur 或 Railway 一家把前端、后端、数据库全放下，中文界面、上手最低优先选 Zeabur；代价是灵活性和可迁移性不如分开搭配，但对第一个全栈练手项目完全够用

C

AI 小工具与自动采集站

要 AI 功能或自动抓数据
Vercel 或 Cloudflare Pages ＋ Anthropic 或 Gemini ＋ Apify ＋ Make 或 n8n ＋ Supabase

适合带 AI 功能或要自动抓数据的网站：AI 问答小工具、自动汇总资讯、定时抓价格再展示；页面平台负责展示，AI 负责理解和生成，Apify 负责抓公开数据，Make 或 n8n 负责定时把流程串起来跑，Supabase 负责把结果存下来给页面读

  1. 先按搭配 B 把页面和 Supabase 搭好
  2. 去 Anthropic 或 Gemini 申请接口密钥，先在本地或平台的函数里调通一次问答
  3. 在 Apify 选一个现成抓取器跑通，确认能拿到想要的数据格式
  4. 在 Make 或 n8n 里把流程串起来：定时触发、调用 Apify 抓取、交给 AI 整理、写入 Supabase
  5. 页面只读 Supabase 里整理好的结果展示

两个二选一：AI 大脑在 Claude 和 Gemini 之间选一个起步就够；自动化在 Make 和 n8n 之间，不想自己部署、想拖拽上手选 Make，想免费自部署、数据自己掌控选 n8n；进阶插件等站跑起来再加，不用一开始就配

一条硬规矩：AI 的接口密钥只能放在服务器一侧（平台的函数或环境变量里），绝不能写进网页前端，写进去等于公开送人

怎么选：三个问题定搭配

你的情况选哪套说明
只展示内容，不要登录搭配 A纯静态最省心，先把网站上线再谈其他
要注册登录、要存数据搭配 B加 Supabase 一层即可，不用自己搭后端
要 AI 功能或自动抓数据搭配 C在 B 的基础上加 AI、Apify 和自动化
说不清，先练手搭配 A 起步需求长出来再往 B、C 升，静态页面迁过去不费劲

费用口径统一说一次：三套搭配起步都可以零元，免费额度对学习和个人小流量通常够用；开始付费的触发点也很一致：流量或用量超出免费额度、要长期常驻不休眠的后端、AI 按调用量计费、抓取按运行量计费、以及自己买域名；各家具体价格和额度经常调整，本文不写死数字，动手前到官网定价页看一眼现行口径为准；抓数据时只抓公开内容，并遵守目标网站的规则和条款

回到最开始的问题：这些工具算小白友好，但不是小白专用；它们省掉的是买服务器、配环境和日常运维，专业团队也在大量使用；第一次搭站先用搭配 A 把网站跑起来，需求长出来再往 B、C 升，加 Supabase 的省事、Make 或 n8n 的自动化，以及 Apify 的现成抓取

02

Muse、Cue、Dots、Grok Bot、Gemini Spark、Devin、Hark：背后的大模型与配的云电脑

这一节只看最典型的七个，外加 Cue 的底座 Manus 本体；每个只回答两个问题：背后的大模型到底是谁的，是自研的还是借别家的；后面配的那台云电脑是什么

大模型 ＝ 大脑

负责想和判断，聪不聪明主要看它

Agent 框架 ＝ 调度

负责拆任务、选工具，把活一步步派下去

云电脑 ＝ 工位

负责真的去开浏览器点网页、装软件、跑代码、存文件；只有大脑、没有云电脑的只能在聊天框里回答你，配上云电脑的，你把手机关掉，它还能在云上接着把活干完

这一批的共同点

这七个全都配了云电脑，只是配法不一样：有的常驻，有的按任务临时开

归组口径定死：只看两件事——直接归属的公司是不是中国公司、运营地在哪；「有中国团队、中国人创办」只是出身，只注明、不决定归组；出身、归属、运营地是三件不同的事，不许混；格式统一写成「名称（所属）」，括号里是所属

国外组共 8 条，最典型的七个全在这一组

Muse (Meta)
大模型
自研：Muse Spark 系列，现行 Muse Spark 1.3，由 Meta 的模型实验室做，不是 Llama 那条线；另有一个开源的小版 Muse Glimmer
云电脑
有，叫 Muse Secure VM：每人一台专属云虚拟机，自带浏览器；你关掉应用它还在后台接着干，登录凭据不经过模型本身，敏感动作由独立的 Sentinel 把关
Hark Pro (Hark Labs)
大模型
自研：Hark 自己的 computer-use 模型，驱动云电脑干活的那套就叫 Handoff；路线是先做后训练，再往中训练和自研预训练走，不是套别家的模型改个名
云电脑
有，叫 Handoff：一台专属云电脑，自带浏览器、文件系统和终端，最多同时开 6 个浏览器，替你登录网站、填表、下单、订位和缴费，花钱和发消息前默认先问你
Devin (Cognition)
大模型
混合：有自研的编程模型 SWE 系列，云端任务推荐用 SWE-2，它是由月之暗面的 Kimi K3 再做后训练来的；同时也能在选择器里换成 Claude、GPT、Gemini 等别家大模型
云电脑
有，按任务开：每个任务给一台隔离的云虚拟机，自带终端、代码编辑器和浏览器，自己装依赖、写代码、跑测试，最后交一个合并请求给你审；任务结束，这台机器就回收
Dots (OpenAI)
大模型
自研：OpenAI 的旗舰模型 GPT-6 Astra；Dots 住在 ChatGPT 里，是个全天候替你盯着目标干活的 Agent，它自己更像调度，写代码和做文档这类重活会分给 Codex 和 ChatGPT Work 去做
云电脑
有，每个 Dot 一台专属、常驻：一台 Linux 云电脑，自带 Chrome 浏览器，系统和浏览器由 OpenAI 维护；文件、装好的软件和网站登录都留在上面，它能按计划自己醒来干活，你关掉电脑也不耽误
Grok Bot (xAI)
大模型
不公开、自动路由：官方不公布默认用哪个模型，也没有选择器；它按任务自动挑当时最合适的，自家 Grok 4.6 在里面，马斯克还点过名，连 Anthropic 的 Claude Opus 5.5 也会被调到，所以它聪不聪明，取决于这一次被路由到了谁
云电脑
有，一个账号共用一台、常驻：一台 Linux 云电脑，跑在和 xAI 一起做这个产品的 Cursor 的基础设施上；你可以建多个有名字的 Bot，每个 Bot 有自己的一块屏幕，但共用同一台机器、同一套文件和登录，不是每个 Bot 一台
Gemini Spark (Google)
大模型
自研：Google 的 Gemini 系列，发布时跑 Gemini 3.5，后来换到 3.7 Flash，应用里还能选用更新的 Gemini 4 Argon；调度框架叫 Antigravity；它 2026 年 10 月在 Gemini 应用里改名叫 Task，还是同一个东西
云电脑
有，Google Cloud 上的专属虚拟机：带一个云端浏览器，网站登录跨会话留着，还能跑代码、存文件，全天在线，你的设备关了它照样干；这一批里它最谨慎，发邮件和花钱之前一律先等你点头
Cue (Manus)
大模型
没有自研基础大模型：主力调用 Anthropic 的 Claude 做推理和规划，子任务用阿里通义千问的微调版，多个模型按活分工；自研的是 Cascade 这套 Agent 执行框架，不是模型本身，所以论智能度要回第四节看 Claude 和通义千问排在哪；注明：中国团队创办，现归属新加坡公司
云电脑
有，而且配得最全：每个 Agent 配一台自己的云电脑，外加一个独立邮箱、一个电话号码和一个钱包，能代接电话、在你定的预算内付款，你下线以后它在这台机器上接着干
Manus (Butterfly Effect Pte)
大模型
和 Cue 同一个底座：没有自研基础大模型，同样是 Claude 加通义千问微调版在背后，自己的本事在 Cascade 调度框架；注明：中国团队创办，现归属新加坡公司，总部和运营在新加坡、只面向海外用户
云电脑
有，叫常驻云电脑：一台全天在线的 Ubuntu 虚拟机，文件、装好的软件、正在跑的进程都留着，你的电脑关机断网，它照样接着干，Cue 的云电脑就建在这套底座上

Cue 和 Manus 为什么归国外组，一句话说清：直接是中国公司就要受中国监管这一套，麻烦很多，Manus 当年把总部迁到新加坡、把运营主体换成新加坡的 Butterfly Effect Pte（开曼架构控股），正是为避开这个，所以按归属和运营地它算国外，出身是中国团队创办只在这里注明；后来腾讯牵头的中方资本回购后成了它最大单一股东，但那是少数股权、不控股，公司还是独立运营、总部仍在新加坡，所以归属不变

国内组按定死的口径，这一批为空

这一批里，国内组是空的：没有一个是「直接归属中国公司、又在中国运营」的，最接近的 Cue 和 Manus 也只是中国团队创办出身，归属和运营都已经在新加坡，所以归国外组；这一组不硬凑数，不拿出身当归组，也不拿不相干的产品来填

从大模型这一项看，几家的含金量也清楚了：Muse、Hark、Dots 和 Gemini Spark 是自己养模型，脑子是自己的；Devin 一半自己养、一半可换别家的；Grok Bot 不公开用谁、按任务自动路由，自家的和别家的都可能被调到；Cue 和 Manus 没有自己的脑子，聪明程度取决于它调用的 Claude 和通义千问，自己的本事在调度和那台云电脑上

云电脑到底是什么，为什么这一代都要配一台

云电脑不是网盘，也不是你远程登录上去办公的那种桌面，它是专门给 Agent 住的一台云端机器：有浏览器、有终端、有文件系统，能登录网站、下载和保存文件、装软件、跑代码；区别只在于是常驻还是临时开：常驻的像给 Agent 租了一间一直开着的办公室，文件和进度都在里面，下次接着用；临时的像每接一个任务临时开一间工作间，活干完就退掉

产品（所属）云电脑的名字常驻还是按任务开你离线后
Muse (Meta)Muse Secure VM常驻，每人一台专属关掉应用继续干
Hark Pro (Hark Labs)Handoff专属云电脑，按任务干活关掉应用继续干
Cue (Manus)Manus 常驻云电脑常驻，全天在线的 Ubuntu 虚拟机下线以后继续干
Devin (Cognition)云端虚拟机（Devbox 一类工位）按任务开，任务完回收关掉自己电脑继续干，干完交合并请求
Dots (OpenAI)无专门名字，每个 Dot 自带一台常驻，每个 Dot 一台专属关掉电脑继续干
Grok Bot (xAI)无专门名字，账号共用一台常驻，一个账号一台、多个 Bot 共用关掉应用继续干
Gemini Spark (Google)无专门名字，Google Cloud 专属虚拟机常驻，专属虚拟机全天在线设备关机继续干

它和自己租的云服务器不是一回事：自己租的服务器是通用机器，装什么、怎么用都由自己定；这里这台是产品方替 Agent 备好的专属工位，不用自己装、不用维护，也不能拿它当自己的服务器用，就是给这个 Agent 干活住的

以后再看到一个新的 Agent 产品，就问三句，立刻能看懂它：第一句，背后的大模型是谁的，自研还是借的；第二句，后面配没配云电脑，叫什么；第三句，那台云电脑是常驻的还是干完一个任务就没了的；第四节管第一句，这一节管后两句

03

自办虚拟卡选型

前面几节选的 AI 订阅大多要绑一张能付美元的卡，这一节讲怎么自己办一张自己名下的 Visa 虚拟卡：自己在发卡平台注册、实名、充值，付正价订阅，不用小贩卖的成品卡、长租卡

定版与用途

路线

自己在发卡平台注册、实名、充值，开自己名下的 Visa 虚拟卡，付正价订阅；不用小贩成品卡、长租卡

充值

用 USDT 充，按月充、按月花，不在卡里存大额

用途

付 AI 订阅月费；过 Muse 年龄验证（卡预授权 1 美元，5–7 个工作日退）

先分清

小贩卖的 0 刀耗材卡是另一回事，0 刀卡过不了 Muse 验证

五家对比只看这五家，结论和数字都已定版，动手前再到各家 App 或官网核一眼现行口径

Gate 卡平台最稳
定位

怎么用这两张榜

一句话总结：最聪明的是 Claude、Gemini、GPT 三家，最热的是 ChatGPT、Meta AI、Gemini、豆包；国内智能看通义和 DeepSeek，热度看豆包、通义、DeepSeek

做纯展示站（搭配 A）用不上 AI；要登录与数据（搭配 B）一般也先不用；只有做 AI 小工具或自动采集站（搭配 C）时才选大脑：要上限看智能度榜前列，要省钱与中文顺手看 DeepSeek、通义千问、豆包、Kimi、GLM；写代码第一梯队是 Claude、GPT、Gemini、DeepSeek、通义千问，这 5 个轮着用基本够了；一个够用，互为备用再加第二个

国内这 14 家共同的好处是不用绕海外网络、中文原生、API 便宜，站要面向国内用户、调用量又大时优先用它们；能开源自部署的是 Llama、通义千问、DeepSeek、GLM、Mistral，能搬回自己的服务器上自己跑，其余都是只能调人家云上 API；接口密钥的规矩不变：只能放服务器一侧，绝不能写进网页前端
