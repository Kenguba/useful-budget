# AI 味审计清单

审计参考，逐项排查页面时按需读；不替代 [frontend/README.md](README.md) 规范正文，冲突以正文为准（如渐变口径：整片平滑渐变可留；主题选中高亮的光晕保留）。每行前为征兆、后为改法。

## 表面与颜色

- 背景、卡片、按钮、选中导航上的紫蓝/紫粉渐变 → 一套中性表面，强调色只用在有意义处
- 标题、数字、标志用渐变文字 → 主文字色实色
- 彩色发光（发光阴影、emoji 投影发光、发光胶囊）→ 去掉，深度靠表面台阶与发丝线
- 内容背后的径向色晕、模糊色块 → 去掉（本站口径：整片平滑的表面渐变除外，见正文）
- 霓虹或高对比彩色边框 → 主文字色 6–10% 发丝线
- 同一色相堆五六种近似色调的文字 → 一套中性色阶出主、次、弱三级
- 每个元素都被高亮、没有重点 → 每屏强调色只用一两处
- 带白色内高光和彩色阴影的玻璃卡 → 普通抬升表面加发丝线

## 字形

- 标题字重 800/900 → 400–500，靠字号拉层级
- 全大写加宽字距的标签（如 NAVIGATION）→ 句首大写、正常或略开字距
- 一屏字号字重过多 → 刻度内少数几档，字重只用 400 与 500
- 数字格式混杂（如 $48,210 与 $124,860.40 并存、07 式补零）→ 全屏一种格式、等宽数字
- 小字负字距 → 0 或略正
- 用斜体强调 → 改颜色或字重

## 图标

- emoji 当导航图标、标签装饰或状态（如 🏠 📥 🚀）→ 一套线条图标，或不用
- 胶囊与计数里塞 emoji（如「18 👤」）→ 纯数字
- 图标尺寸、颜色五花八门 → 一个尺寸、一种描边、随文字层级色
- 图标与所在列不对齐 → 每行同一图标框宽
- 用 ✨ 表示 AI → 去掉，或只在能说明问题处用普通图标

## 间距

- 任意值间距（如 13px、7px、31px）→ 4px 刻度
- 同一列表行高、行距不一 → 一个行高、一个间距
- 组与邻组比组内还近 → 组内小、组间大
- 同级卡片内边距不一 → 一个内边距
- 段落上方大片空、下方挤 → 节奏均衡

## 文案

- 问候式标题（如「欢迎回来，Damir！👋」）→ 页面或周期本身作标题
- 感叹号 → 平实陈述
- 变化不带参照（如「+12%!!」）→ 带参照（如「较上月 +12%」）
- 冗长占位符（如「搜索任何东西…」）→ 写短（如「搜索」）
- 浮夸词（supercharge、seamless、unlock、magic 等）→ 写它实际做什么
- 标签与按钮文案末尾带句号 → 不带
- 假得明显的数据（如 $123,456、[X]）→ 可信数字

## 组件

- 计数、套餐、快捷键、状态用发光胶囊 → 安静的等宽纯文字或键帽样式
- PRO、New ✨、Beta 🚀 徽章遍地 → 去掉，或至多一个安静文字徽章
- 从搜索到按钮到卡片全做成胶囊 → 圆角按尺寸分档、嵌套按公式
- 图表彩虹柱、发光柱、胶囊柱、全大写日标签 → 一两个数据系列、网格弱化、等宽标签、一个高亮色
- 每个图都用强调色的多个深浅、没有主次 → 中性阶打底，强调色只点关键项
- 每张数据卡都塞迷你图、走势线 → 只放数字、标签与带参照的变化
- 等宽等样卡片并排连片 → 一个主图、紧凑数据、宽度有变化
- 标志做成渐变砖加闪光、字标渐变 → 产品名实字加简单扁平标记
- 标志是光泽球、渐变球、发光点 → 单色扁平字形，或只用字标

## 落地页与主视觉区

- 标题上方放徽章丸（如「✨ Introducing X 2.0」）→ 去掉；真有新闻时用安静的文字链接
- 标题换哪个产品都成立（如「用 AI 为你的工作流超级加速」）→ 说清这产品为谁做什么
- 标题渐变或闪烁 → 实色文字
- 主视觉区背后漂浮色块、球体、网格、发光线 → 素背景或一张真实产品视觉
- 标题、文案、按钮、图片全居中堆叠 → 不对称分栏，或文字压在大产品图上
- 三个以上按钮、按钮下还堆标签与头像 → 一个主操作、至多一个次操作
- 「深受 10,000+ 团队喜爱」、头像点阵、五星无来源 → 先核实真假，真则写安静具体，否则去掉
- 视差与滚动漂浮 → 静态布局，动效须有目的
- 功能卡每张一个 emoji、一个粗标题、一句空话 → 功能更少、文案具体、线条图标或无图标

## 视觉素材

- 光泽 3D 色块、球体、液态金属、紫色星云当主视觉 → 产品本身，或一个能代表其功能的具象意象
- AI 主题用库存机器人、发光大脑、电路线、全息图 → 去掉，或展示 AI 的实际产出
- 图内烘焙文字、假按钮、假标志 → 页面实字，图片干净无字
- 图片与页面不融合（硬边、底色不同）→ 底色对齐页面、边缘渐隐
- 每个区块都放图 → 只在真正有帮助处放，通常只有主视觉区

## 动效

- 非实时元素用 pulse、ping、呼吸发光 → 静态
- transition-all、卡片按钮悬停放大 → 悬停只变颜色或表面，按压才微缩
- 简单 UI 用弹跳弹簧、过冲 → 一条强缓出曲线
- 入场时各元素从不同方向飞入 → 一次短淡入加轻微上移、逐项小错开
- 视差、漂浮循环、滚动驱动移动 → 静态布局
- 动画宽高、top、left → 只动画 transform 与 opacity

## 模板感（清理后的回退病，收尾时查）

- 纯灰 #161616 页面配白字、只有一个旧品牌色按钮，而产品世界是暖的、亮的 → 色阶向产品世界微染、强调色取自该世界
- 标题换个产品名也成立 → 用产品自己的名词说清它做什么
- 主视觉是空盒子或通用图 → 用代码做产品预览，或用该世界的图
- 每个产品同一套布局、字形、配色 → 由方向决定
