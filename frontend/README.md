# frontend — 前端底线与按需索引

做页面结构、交互或 UI 改动时先读本文件；**仅改 `data/` 或 `scripts/refresh.py` 不必读本文件**。各站实现细则见对应 `frontend/pages/<project>/README.md`。

## 通用交互与基础底线（每次改前端必守）

- **等宽数字（全站适用）**：数值显示统一 OpenType `tnum`（`font-variant-numeric: tabular-nums;`），覆盖金额、价格、数量、时间、日期、百分比与动态数字；不改整段文字为等宽字体、不叠加重复 CSS，核对手机与桌面显示。
- **SPA 单页面与返位**：站内切换不整页重载，返回恢复原视图与滚动位置。
- **交互不重绘**：点按、输入等高频交互就地局部更新、反馈先行，不整表重绘或重排；确需全量对账放下一帧。
- **移动端适配（≤860px）**：所有页面须在手机宽度下正常可用，顶栏/工具栏不可横向溢出撑宽页面（放不下就换行或横滚），内容区满宽；改版或新页上线前按手机宽度逐一核对。`pan-cloud` 专属口径见 [pan-cloud/README.md](pages/pan-cloud/README.md)。
- **点击热区与安全三角**：可点元素热区须大于可见区域，相邻热区紧挨不留缝隙（列表行热区外扩填满行隙）；有子菜单须加安全三角（指针斜移向子菜单时同级暂不切换）。
- **点击高亮与聚焦态**：点按高亮须与元素形状一致（圆形/胶囊不得出现矩形高亮）；输入框/搜索卡聚焦不改边框颜色、只在外侧给淡淡主题光晕（`0 0 0 2px var(--search-glow)` 量级）；跳转/锚点定位高亮不用边框和光晕圈，只用淡色背景闪亮后消失。
- **图标与色阶**：图标一律用内联 SVG 或 ico，不用 emoji；同一套线条/尺寸/描边并随文字层级着色，无信息增量图标去掉；深色模式不得借用浅色背景变实心白块。
- **文案与图表**：页面可见文案行末默认不加句号（单行多句用分号）；时间线/甘特图/对比条/流程图一律用 SVG/Canvas 等图表呈现，不用截图或纯文字凑数。
