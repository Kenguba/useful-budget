# AI账号商铺（ai-shop）

AI 账号比价与店铺目录页：https://kenguba.github.io/useful-budget/frontend/pages/ai-shop/

- `index.html` — 页面（报价单 + 店铺目录，店名可点击进店铺主页）
- `scripts/refresh.py` — 纯代码刷新脚本（零依赖）：抓 AI价网公开分类「全部渠道」页，按固定 7 分组（GPT 日抛未接马/已接马、GPT 周限、反重力最便宜/已过验证、Codex 接码单次、Grok Heavy）取有货最低 10 条，同标题铺货合并；并把 `data/shops.csv` 转成 `data/shops.json`
- `data/board.json` — 报价数据（自动刷新提交）；顶层另含 `prices` 段：看板条目的变价记录（三元交错差分数组，逐点带来源码 1=脚本抓 2=浏览器抓 3=人工补充），变价弹窗直接读这一段
- `data/price-log.json` — 全量变价池 v3：`items` 三元交错差分数组（每点：时刻/间隔、价、来源码）；键为「平台短码:商品ID」（仅 4 家聚合平台）或整链接（个人店铺/自建站，www 归一）
- `data/maps.json` — 平台映射本体（只收聚合平台 4 家：wzyp 链动小铺 / 16688 / catfk 云猫寄售 / aicdks，各带 name、goods 商品前缀、shop 店铺入口前缀）；个人店铺不进表
- `data/shops.csv` — 店铺总目录源数据（人工/周报更新后替换此文件）
- `data/shops.json` — 目录页数据（由 refresh.py 生成，独立于 maps）

## 数据规范

- 数据三件：price-log.json 全量池（价格史）、board.json 看板（自带 prices 价格史段）、maps.json 平台映射；shops.json 店铺目录独立；direct16688 / overrides / browser-pool 是缓存与输入，不算本体
- 唯一键：商品链接唯一，标题不进键；聚合平台（wzyp / 16688 / catfk / aicdks）键为「短码:商品ID」，个人店铺键为整链接（www 归一）
- 平台映射：maps.json 只收聚合平台，条目含 name、goods 商品前缀、shop 店铺入口；双向使用，encode 整链接→键、decode 键→整链接，取数据先查映射；个人店铺不进映射
- 来源：差分数组每点三元（时刻/间隔、价、来源码）:1 脚本抓、2 浏览器抓、3 人工补充；同轮覆盖优先级 3>2>1；存量点回填 1，新点逐点精确
- 库存：stock 数字为现售库存，0 售罄（有链接照常入池），null 失效（链接不可以用：商品不存在/详情打不开），无 stock 记录为未知；没链接的商品不收；看板见 null 剔除，记录不删；-1 不再使用
- 只存不删：所有数据只保存、不物理删除，字段也不为省空间删除；结构调整只搬家、逐条对账
- 失效归档：总量超过 100 万条时，间隔周期大于 7 天的失效数据移入「失效」文件保存
- 16688 取价：电脑端店铺页预览全部商品，tab 逐个点开，逐件进详情页取 ID 与最新价；同一标签页改地址跳转，不新开页窗

更新方式：根 workflow 每 12 小时自动跑刷新并发布。本地手动刷新：`python3 scripts/refresh.py`。
口径说明（v2）：按商家遍历——AI价网全量商家商品库（/api/shop-products.json，2052 家店每店全部分类与全部商品）+ cardnav 同格式全量库（966 家）按商品链接去重合并，再叠加 PriceAI 商品页最低价段（按价升序前 12 条）；随后按固定 7 分组标题规则分类取有货最低 10 条。不再只看聚合分类榜单页（有「只看标准商品」过滤与快照滞后）。

## Cookie A 实现细则

ai-shop 是单槽（2026-11-04 晚改定，全站一套主题）：localStorage `aishop.theme.v1` 存 `{t, d}`，t 为全站唯一主题位（0–11 对应 1–12 套）、d 为日夜；报价单与店铺目录两个页签共用同一套主题，切页签不换色、也不写 `A`；读 `A` 时主题号直接就是全站主题；只有在主题面板里真正点选 / 滑选了颜色、或单击主题钮切换日夜时才写 `A`；旧版双槽存量 `{q, s, d}` 首次打开时按 q（原报价单槽）迁移为 t，`A` 存在时以 `A` 为准
